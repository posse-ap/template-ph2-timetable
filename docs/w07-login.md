# W7 ログイン機能仕様書

## 1. 対象画面
- GET /register：登録画面
- POST /register：ユーザー登録
- GET /login：ログイン画面
- POST /login：ログイン認証
- POST /logout：ログアウト

## 2. ユーザー登録
入力項目：名前、メールアドレス、パスワード、確認用パスワード

バリデーション：
- 名前必須：名前を入力してください
- メール必須：メールアドレスを入力してください
- メール形式：メールアドレスの形式で入力してください
- メール重複：このメールアドレスはすでに登録されています
- パスワード8文字以上：パスワードは8文字以上で入力してください
- パスワード確認不一致：パスワードが確認用と一致しません

登録成功後は自動ログインし、/entries に移動する。
パスワードはハッシュ化して保存する。

## 3. ログイン
- メールアドレスとパスワードで認証する
- 成功後はセッションを再生成する
- 成功時は /entries に移動する
- 失敗時は「メールアドレスかパスワードが違います」を表示
- 失敗時も入力したメールアドレスを保持する

## 4. ログアウト
- POST /logout でログアウトする
- セッションを無効化する
- /login に移動する

## 5. アクセス制御
- /entries と /courses はログイン必須
- 未ログインでアクセスした場合は /login に移動する
